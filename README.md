- **静态站、个人博客、单条对外 API**：VM-1 起步。2GB 内存是 PHP 和 MySQL 同机不憋屈的下限。
- **一个 WordPress 加数据库、或者三四个 Docker 容器**：VM-1.5。多出来的那个核在插件多、并发上来的时候会救你一次。
- **多站点、小型数据库、轻量爬虫**：VM-2 起，并发要求高就 VM-3。
- **要装 Windows Server**：VM-4 起步。4GB 内存跑 Windows 加业务会一直卡在内存不足上，8GB 才是能用的起点。
- **16GB 以上**：VM-8 和 VM-12，除非你明确知道自己要跑什么，否则用不到。

## 下单前确认这几件事

1. **支付方式和币种**。页面以美元标价，用人民币卡付款可能产生货币转换费，实际扣款金额跟标价会有出入。
2. **退款条款**。定价页不写退款窗口，去条款页确认一遍；如果结算时用了促销码，退款资格可能受影响。
3. **账单周期和下一期金额**。结算页会显示周期，确认是月付还是年付、下一期扣多少，再点确认。
4. **IP 属性自检**。低价德国 VPS 多数是机房段 IP，被平台判定为 datacenter 是常态。做 TikTok、流媒体、AI 平台之前，用 ipinfo、scamalytics、whoer 交叉查一遍，三个库结果不一致很常见，别只信一个。
5. **晚高峰三网实测**。ping.pe 看延迟和丢包，itdog.cn 看全国节点，besttrace 看回程路由。测试时间选晚上 8 点到 11 点，白天测出来的数字没什么参考价值。
